From Visual to Sensory

보는 방식이 달라도,
선택은 나답게.

Stylens는 시각 중심의 의복 선택 과정을 음성, 촉각, 개인화 추천으로 다시 설계합니다. 정보를 대신 결정해주는 것이 아니라, 사용자가 스스로 판단할 수 있는 단서를 제공합니다.

01 · Listen

옷의 정보를
듣고 이해하기

색상, 소재, 형태처럼 눈으로 확인하던 정보를 구체적인 언어로 바꿔 전달합니다.

02 · Touch

손끝으로
빠르게 구분하기

점자 링과 분류 방식을 통해 옷장에서 원하는 옷의 위치와 종류를 더 쉽게 찾습니다.

03 · Choose

상황에 맞게
스스로 선택하기

날씨, 일정, 취향을 함께 반영해 추천 이유까지 듣고 최종 선택은 사용자가 직접 합니다.

Core Functions

4가지 핵심 기능

옷을 발견하고 이해하는 순간부터 최종 스타일을 선택하기까지 하나의 흐름으로 연결됩니다.

01 — 04
FUNCTION 01

옷 인식

카메라가 옷의 카테고리와 색상, 형태, 소재를 분석해 사용자가 이해할 수 있는 정보로 변환합니다.

색상 분석 종류 구분 소재 정보
FUNCTION 02

음성 안내

인식된 옷의 특징과 추천 이유를 구체적인 언어로 안내하여 화면을 자세히 보지 않아도 정보를 확인할 수 있습니다.

고대비 화면 상세 음성 설명 단계별 안내
FUNCTION 03

코디 추천

보유한 옷과 현재 날씨, 외출 목적, 사용자의 취향을 함께 분석해 상황에 어울리는 코디를 제안합니다.

날씨 반영 일정 분석 취향 학습
FUNCTION 04

촉각 링

옷걸이 목부분의 촉각 링과 상·하의 분류 케이스를 활용해 옷을 손으로 구분하고 쉽게 찾을 수 있도록 돕습니다.

촉각 링 상의·하의 구분 손쉬운 탐색
