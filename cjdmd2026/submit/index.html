제출 후, 우리 팀 주소에서 모든 페이지를 확인해주세요.

본인 팀의 프로젝트만 수정해주세요. 다른 팀 프로젝트에 파일을 추가·교체·삭제하는 행위는 금지합니다. 반영된 변경사항은 접수번호·반영 시각·대상 팀·파일 변경 이력으로 기록됩니다. 로그가 남으므로 무단 변경 내역을 추적·확인할 수 있습니다. 팀을 잘못 선택했다면 업로드하거나 변경사항을 반영하지 말고, 본인 팀을 다시 선택해주세요.

페이지에서 사용하는 CSS·이미지·영상 등이 빠지거나 파일명이 다르면 화면이 깨질 수 있어요. 제출 시스템은 선택한 파일과 폴더 구조를 저장하며, 코드 안의 연결 경로를 자동으로 수정하지 않습니다.

  • 첫 화면과 하위 페이지에 필요한 파일 모두 포함
  • 폴더명·파일명·대소문자·확장자 일치
  • 배포 후 메뉴·이미지·영상·버튼 직접 확인

이미지 제출 형식: WebP·AVIF·JPG/JPEG·SVG·GIF만 받습니다. 파비콘용 ICO도 허용합니다. PNG·BMP는 업로드할 수 없으며, 이미 저장된 파일은 유지됩니다.

파일 연결과 수정 제출 방법 +
  1. 사이트 폴더 가져오기: index.html이 바로 들어 있는 폴더를 선택하세요. 팀 폴더는 자동으로 연결되므로 같은 이름의 팀 폴더를 안에 한 번 더 만들지 마세요. css, js, 이미지·영상 폴더와 하위 HTML도 함께 준비해주세요.
  2. 경로는 파일 위치에 맞게: HTML은 해당 HTML 위치, CSS의 url()은 해당 CSS 위치를 기준으로 연결합니다. 아래는 assets/images/photo.webp를 불러오는 예시입니다.
    • index.html에서 → ./assets/images/photo.webp
    • pages/detail.html에서 → ../assets/images/photo.webp
    • css/style.css에서 → url('../assets/images/photo.webp')
    /assets/...는 전시 사이트 최상위를 가리킵니다. 팀 폴더 안의 파일에는 위와 같은 상대경로를 사용하고, localhost나 C:\... 같은 내 컴퓨터 주소는 제거해주세요.
  3. 파일명까지 정확하게: Photo.jpg와 photo.jpg, .jpg와 .webp는 서로 다른 파일입니다. 이미지를 WebP 등으로 변환했다면 HTML·CSS·JS에서 참조하는 이름도 함께 바꿔주세요. 확장자만 바꾼 PNG·BMP도 제출할 수 없습니다. 비어 있는 src=""와 아직 만들지 않은 페이지 링크도 확인해주세요.
  4. 반영 후 전체 화면 점검: 배포가 끝난 뒤 팀 주소에서 첫 화면뿐 아니라 모든 메뉴와 하위 페이지, 영상 재생, 버튼을 확인해주세요. 개발자 도구의 Network에서 404가 뜨면 요청된 경로에 파일이 있는지 확인하세요.
  5. 빠진 파일은 추가 제출: 파일 관리에서 올바른 폴더로 이동해 누락 파일을 추가하거나, 수정한 사이트 폴더를 가져온 뒤 업로드하고 ‘변경사항 반영’을 누르세요. 같은 경로의 파일은 교체되고 나머지는 유지됩니다. 이름을 바꾼 이전 파일은 필요할 때 직접 삭제해주세요. 나눠 제출했다면 필요한 파일을 모두 반영한 뒤 최종 확인해주세요.

이미지와 CSS 경로는 ./images/photo.jpg처럼 상대경로를 사용해주세요. React·Vite 프로젝트는 빌드한 dist 폴더를 선택해주세요.

이미지는 WebP·AVIF·JPG/JPEG·SVG·GIF로 제출해주세요. 파비콘용 ICO도 허용합니다. PNG·BMP는 새로 업로드할 수 없습니다. 디자인 도구의 ‘웹용으로 저장’ 또는 ‘내보내기’로 실제 형식을 변환하고, 화면에 필요한 해상도와 품질로 용량을 줄여주세요. 투명 배경은 WebP·AVIF 등을 이용하세요. 파일 확장자만 바꾸면 제출할 수 없습니다. 변환 후 HTML·CSS·JS의 연결 경로와 이미지·글자의 선명도를 확인해주세요. 이미 저장된 PNG·BMP는 유지되므로, 다른 파일만 수정할 때는 수정한 파일만 추가해주세요.

전체 500 MiB, 개별 파일은 95 MiB까지 가능합니다. 큰 영상은 용량을 줄이거나 외부 링크로 연결해주세요. node_modules, .git, 환경변수 파일과 디자인 원본은 제외해주세요.

한 번에 한 팀씩 제출합니다. 업로드가 끊겨도 30분 안에 같은 브라우저에서 같은 폴더를 다시 선택하면 완료된 파일은 건너뜁니다. 30분 이상 진행이 없으면 다음 접수 전에 임시 파일이 정리됩니다. 파일 내용을 수정했다면 새 제출을 시작해주세요.
