2D 아이콘 패턴 → 결합   |   main/index.html 발췌

1. ZIP 전체를 한 폴더에 압축 해제합니다.
2. index.html을 Chrome, Edge 또는 Safari 등 WebGL 2를 지원하는 브라우저에서 엽니다.
3. 아래로 스크롤하거나 ‘결합 보기 ↓’를 누릅니다. 세로 ‘결합’이 완성되면 그 화면에 머뭅니다.
   위로 스크롤하거나 ‘패턴으로 돌아가기 ↑’를 누르면 반대로 재생됩니다.
   터치 화면은 위·아래로 쓸어 넘길 수 있습니다. 방향키 ↓·↑로도 조작할 수 있습니다.

미리보기에는 인터넷, 서버, 패키지 설치가 필요하지 않습니다.

파일 안내
  index.html, demo.js        완성된 오프라인 실행본. 두 파일을 같은 폴더에 두세요.
  art/gyeolhap.svg           밝은 포스터에서 세로 ‘결합’ 도형만 추출한 편집용 벡터. 배경은 투명합니다.
  art/icons/                 시작 패턴에 쓰인 개인 아이콘 33종. 개별 SVG로 편집할 수 있습니다.
  assets/icons.json          실행에 쓰는 33종의 SVG 경로와 색상
  assets/word-layout.json    ‘결합’ 조각 7,594개의 원본 위치·크기 및 텍스처 좌표
  assets/word-atlas.webp     각 조각의 실제 색과 모양이 담긴 이미지

원본 메인과 마찬가지로, 전환은 한 장의 SVG를 확대하는 것이 아니라 각 조각을 다른 깊이에 놓고
카메라를 뒤로 이동시키며 원래 자리로 모으는 방식입니다. 완성 후에도 주변의 작은 조각은 부유합니다.
art/의 SVG는 개별 사용·편집용입니다. 이 파일만 바꿔도 실행본이 바뀌지는 않습니다.

다른 페이지에 적용하거나 동작을 수정할 때
  src/demo.js                데모 시작, 화면 크기 맞춤, 마지막 장면 유지
  src/flat-pattern.js        원본의 수직 카메라와 반복 패턴 배치
  src/word-surface.js        main-hero.js에서 분리한 조각의 위치·부유·주변 분포
  src/word-flight.js         카메라 이동, 색 조각의 깊이와 결합
  src/main-handoff.js        원본의 스크롤·터치 입력, 왕복 시간 및 방향 전환
  src/grid-defocus.js        멀어지는 패턴을 흐리게 그리는 효과

실행 코드는 src/와 assets/를 수정한 뒤 다시 빌드합니다. Node.js 22 이상에서 이 폴더를 열고
npm install, npm run build를 순서대로 실행하면 demo.js가 갱신됩니다.
Three.js 라이선스는 licenses/three.txt에 있습니다.
